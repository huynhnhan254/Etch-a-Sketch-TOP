# Etch-a-Sketch-TOP

A browser-based Etch-a-Sketch drawing app built with HTML, CSS, and JavaScript.

Features
Generate a customizable grid from 1x1 to 100x100
Draw by hovering over the grid cells
Random RGB colors are generated for each cell
Cells progressively darken with each interaction
Cells become fully colored after 10 interactions
Reset the grid with a custom size
Responsive flexbox-based grid layout
Styled buttons and grid for a clean interface
Technologies
HTML5
CSS3
JavaScript
DOM Manipulation
Flexbox
How to Use
Open the project in a web browser.
Move your mouse over the grid to draw.
Each cell starts with a random color.
Continue hovering over a cell to progressively darken it.
Click the Size button to create a new grid.
Enter a number from 1 to 100 for the number of squares per side.
